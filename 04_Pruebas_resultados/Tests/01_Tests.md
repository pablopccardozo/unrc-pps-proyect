# Mediciones de métricas

* End-to-End Packet Delay: Para voz en tiempo real, el objetivo es <150 ms.

* Packet Loss Rate: Objetivo <5% para voz.

* Throughput: La cantidad de datos de audio entregados exitosamente por unidad de tiempo.

* Parámetros de simulación de referencia (Tablas 1.0-1.2)[01]

* Tamaño de cola promedio. (se puede obtener monitoreando los buffers de la app o del sistema operativo).
