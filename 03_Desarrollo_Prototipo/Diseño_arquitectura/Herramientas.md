# Posibles Herramientas de medición 

* Candela LANforge: Para emular decenas de clientes Wi-Fi y generar perfiles de tráfico realistas (streaming, descargas, IoT).

* Monitoreador de latencia personalizado: Usar port mirroring y marcas de tiempo hardware para medir latencia unidireccional de extremo a extremo (cliente-AP).

* Calnex Paragon: Emulador de WAN para añadir latencia fija (80 ms en este caso).
